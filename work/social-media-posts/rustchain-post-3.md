RustChain: Your Old Mac/SPARC/SGI Could Be Earning Crypto While Preserving Computing History

## Post Content

Hey vintage computing enthusiasts!

I came across a project that might interest this community - RustChain. It's a blockchain network specifically designed for retro computing hardware.

**The gist:**
- Install a lightweight client on your vintage machine (G3, G4, G5, SPARC, MIPS, etc.)
- The machine periodically sends cryptographic attestations proving it's still operational
- These attestations get recorded on-chain
- You earn RTC tokens for each attestation
- Your machine builds an on-chain "biography" - when it came online, its architecture, its history

**Why I think this is cool for vintage computing:**

1. **Economic incentive to maintain old hardware** - Your collection can literally pay for its own upkeep
2. **Decentralized registry** - Creates a global database of working vintage machines
3. **Provenance tracking** - Buy a machine and see its on-chain history
4. **Community building** - Connect with other collectors through the network

The project is fully open source (Rust) and they have bounties for contributors if you want to get involved.

Links:
- Main site: https://rustchain.org
- GitHub: github.com/Scottcjn/Rustchain
- Python client: pypi.org/project/clawrtc/

Has anyone here tried it? Would love to hear experiences with running it on different hardware!
