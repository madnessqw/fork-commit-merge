### Yeni Fikir #1

**Slug:** `process-monitor-cli`
**Name:** Process Monitor CLI
**Description:** Local veya SSH ile remote sunucudaki process'leri listeler — PID, CPU%, MEM%, runtime. `ps aux` streaming, sort by memory/CPU, kill signal gönderebilir. Stateless API, no DB.
**Price:** $14 one-time
**Why Now:** Container/serverless ortamlarda process management için basit bir CLI tool eksik. AWS Lambda, Vercel Functions "process" kavramı olmasa da developer'ların local debug için ihtiyacı var.
**Giriş Noktası:** `docker-run-generator` ve `env-file-manager` ile cross-sell

### Yeni Fikir #2

**Slug:** `secret-rotator`
**Name:** Secret Rotator
**Description:** Environment variable'ları rotate eder — `.env` dosyasındaki API key'leri yenisiyle değiştirir, eskisini invalidates. Rotation schedule'u cron ile tetiklenebilir. Stateless, no tracking.
**Price:** $19 one-time
**Why Now:** 2026'da AI agent'lar çok sayıda API key kullanıyor. Key rotation manual yapılıyor, güvenlik riski. `envguard-pro` ile tamamlayıcı.
**Giriş Noktası:** `envguard-pro`, `env-file-manager` ile cross-sell

---

### Yeni Fikir #3

**Slug:** `cron-health-checker`
**Name:** Cron Health Checker
**Description:** Verilen cron expression ve son çalışma zamanını analiz ederek "sağlıklı mı?" döner. Expression validity + expected next run + timezone correctness kontrolü. Webhook ile sonuç döner.
**Price:** $12 one-time
**Why Now:** `cron-expression-builder` ve `cronmaster` var ama "cron çalışıyor mu?" kontrolü yok. Developer'lar cron job'larının gerçekten tetiklendiğinden emin değil — bu tool o güveni verir.
**Giriş Noktası:** `cron-expression-tester`, `cronmaster` ile cross-sell

### Aksiyon

3 fikir de developer workflow'a odaklı, one-time pricing, stateless serverless deploy uygun.

**Önerilen öncelik:** `cron-health-checker` ($12) → en düşük friction, mevcut cron araçlarıyla güçlü cross-sell.
