Frequently Asked Questions

Which hash algorithm should I use?

Bcrypt is recommended for maximum security. MD5 is widely compatible with older systems. SHA1 offers a balance between security and compatibility.

Is this compatible with both Apache and Nginx?

Yes! Generated .htpasswd files work with Apache's mod_auth_basic and Nginx's auth_basic module.

Can I generate multiple users at once?

Absolutely. The Pro version includes bulk generation for entire teams or organizations.

Are passwords stored securely?

Passwords are hashed client-side using industry-standard algorithms. We never store or transmit plain text passwords.
