# JWT Debugger Pro

A professional JWT (JSON Web Token) debugging and verification tool for developers.

## Features

- **🔓 Instant Decoding**: Paste any JWT token to instantly decode header, payload, and signature
- **🎨 Syntax Highlighting**: Beautifully formatted JSON with color-coded syntax
- **⏰ Timestamp Analysis**: Automatic detection and interpretation of iat, exp, nbf, auth_time claims
- **🔐 Signature Verification**: Verify HMAC signatures with your secret key
- **📊 Token Statistics**: Real-time display of token length, algorithm, and type
- **💾 Sample Tokens**: Built-in examples for testing (Basic, Expired, Firebase-style)
- **📱 Responsive Design**: Works perfectly on desktop, tablet, and mobile
- **⚡ Offline Capable**: Single HTML file - no server required, works offline

## Use Cases

- Debug authentication tokens during development
- Inspect third-party JWT tokens
- Verify token expiration and validity
- Learn JWT structure and encoding
- Test signature verification

## How to Use

1. Open `index.html` in any modern browser
2. Paste your JWT token in the input field
3. View decoded header, payload, and signature instantly
4. Use the Signature Verification panel to validate tokens
5. Check Timestamp Analysis for expiration info

## Technical Details

- Pure HTML/CSS/JavaScript - no dependencies
- Supports all standard JWT algorithms (HS256, HS384, HS512, RS256, etc.)
- Base64Url decoding with proper padding handling
- Secure client-side processing - tokens never leave your browser
