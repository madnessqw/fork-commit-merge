Frequently Asked Questions

What is DNS over HTTPS (DoH)?

DNS over HTTPS is a protocol for performing remote DNS resolution via the HTTPS protocol. It provides encrypted DNS queries for enhanced privacy and security.

How does DNS propagation checking work?

We query multiple DNS resolvers located in different geographic regions to check if your DNS changes have propagated globally. This helps identify propagation delays during domain migrations.

What record types are supported?

We support all common DNS record types including A, AAAA, MX, NS, TXT, CNAME, SOA, SRV, and PTR records.

Is there an API available?

Yes! Pro users get access to our REST API for programmatic DNS lookups, batch queries, and integration with your existing tools and workflows.
