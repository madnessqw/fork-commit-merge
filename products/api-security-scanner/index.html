Frequently Asked Questions

Is the free scan safe to use on production APIs?

Yes, our scans are read-only and non-intrusive. We only analyze responses and headers without modifying any data. However, we recommend testing on staging environments first.

What vulnerabilities can the scanner detect?

We detect OWASP API Top 10 vulnerabilities including broken authentication, excessive data exposure, lack of rate limiting, security misconfigurations, injection flaws, and more.

How long does a scan take?

Most scans complete within 30-60 seconds depending on the API size and complexity. Our Pro plan includes faster parallel scanning.

Can I integrate this into my CI/CD pipeline?

Yes, Pro users get access to our API and CLI tools for seamless CI/CD integration. You can automate security scanning on every deployment.

Do you store my API data?

No. We never store your API responses or sensitive data. Scan results are ephemeral and only available during your session.
