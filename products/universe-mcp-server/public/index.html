How to Connect

Add this to your Claude Desktop or any MCP client config:

POST  https://universe-mcp-server.vercel.app/mcp

Claude Desktop Config (claude_desktop_config.json)

"mcpServers": { "universe": { "command": "fetch", "url": "https://universe-mcp-server.vercel.app/mcp" } }

Test the connection

curl -X POST https://universe-mcp-server.vercel.app/mcp \ -H "Content-Type: application/json" \ -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}'
