# Base64 Encoder Pro

Professional Base64 encoding/decoding tool for developers.

## Features

- **Encode/Decode**: Convert text to Base64 and back
- **URL-Safe Mode**: Replace +/ with -_ for URL compatibility
- **Padding Options**: Remove padding characters (=)
- **Real-time Stats**: Input/output character count, size ratio, bytes saved
- **One-click Copy**: Copy results instantly
- **Swap Function**: Quickly swap input and output
- **Sample Data**: Load sample text for testing

## Usage

1. Open `index.html` in any modern browser
2. Enter text in the Input field
3. Click "Encode" or "Decode"
4. View results in the Output field
