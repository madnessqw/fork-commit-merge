# AI Web Scraping Toolkit

## Ürün Açıklaması
Python tabanlı, AI destekli web scraping araç seti. Veri çıkarma, temizleme ve analiz için hazır script'ler.

## İçerik
- `scraper_base.py` - Temel scraping class
- `ai_extractor.py` - LLM tabanlı veri çıkarma
- `proxy_rotator.py` - Proxy yönetimi
- `data_cleaner.py` - Veri temizleme utilities
- `examples/` - 5 farklı site örneği
