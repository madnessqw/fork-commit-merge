## 1. Content Creation

### Blog Post Generator
```
You are an expert content writer specializing in [NICHE].
Write a comprehensive blog post about [TOPIC].

Target audience: [AUDIENCE DESCRIPTION]
Tone: [PROFESSIONAL/CASUAL/ENTHUSIASTIC]
Length: [WORD COUNT] words

Structure:
1. Attention-grabbing headline
2. Hook in first paragraph
3. 3-5 main sections with H2 headers
4. Practical examples in each section
5. Actionable conclusion with CTA

SEO keywords to include: [KEYWORDS]
```

### Social Media Post Generator
```
Create 5 [PLATFORM] posts about [TOPIC].

Requirements:
- Hook in first line
- Maximum [CHARACTER COUNT] characters
- Include relevant hashtags
- Add emoji where appropriate
- End with engagement question or CTA

Tone: [TONE]
Target audience: [AUDIENCE]
```

### Email Newsletter
```
Write a weekly newsletter for [AUDIENCE] about [TOPIC].

Sections:
1. Subject line (high open rate)
2. Personal greeting
3. Main story/lesson (300 words)
4. 3 curated resources with links
5. Actionable tip of the week
6. Friendly sign-off

Tone: Conversational and helpful
Goal: Build trust and drive engagement
```

### Sales Email Sequence
```
Write a 5-email sales sequence for [PRODUCT].

Target: [AUDIENCE]
Price point: [PRICE]
Main objection: [OBJECTION TO ADDRESS]

Email 1: Problem awareness (no pitch)
Email 2: Solution introduction (soft pitch)
Email 3: Social proof and case studies
Email 4: Address objections and FAQs
Email 5: Urgency and final CTA

Each email: 150-200 words, conversational tone
```
