# Python DevToolkit

A collection of practical Python automation scripts for developers.

## What's Included

1. **file_organizer.py** - Automatically organize files by type/extension
2. **duplicate_finder.py** - Find and optionally remove duplicate files
3. **bulk_renamer.py** - Rename files in bulk with patterns
4. **folder_sync.py** - Sync two folders (one-way or bidirectional)
5. **log_analyzer.py** - Parse and analyze log files

## Installation

```bash
pip install devtoolkit
```
