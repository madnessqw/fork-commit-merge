# Website Uptime Monitor with Alerts

A production-ready Python script that monitors your websites 24/7 and sends instant alerts via Discord, Slack, Telegram, or email when downtime is detected.

## Features

- **Multi-site monitoring** - Monitor unlimited websites
- **Multiple alert channels** - Discord, Slack, Telegram, Email (SMTP)
- **Configurable check intervals** - Every minute, 5 minutes, etc.
- **Retry logic** - Avoid false positives from temporary blips
- **Status history** - Track uptime percentage and response times
- **JSON/CSV export** - Generate reports for clients
- **Lightweight** - Runs on any VPS, Raspberry Pi, or local machine

## Use Cases

- Freelancers offering uptime monitoring as a service ($50-200/month per client)
- DevOps teams needing simple monitoring
- SaaS founders monitoring their own products
- Agencies providing value-added services to clients

## Quick Start

```bash
# Install dependencies
pip install requests

# Configure your sites in config.json
python uptime_monitor.py
```
