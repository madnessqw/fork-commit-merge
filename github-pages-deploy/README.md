# GitHub Pages Deployment Package

## Quick Deploy Instructions

1. Create a new GitHub repository named `UniverseCreator-tools` (or any name)
2. Run these commands:

```bash
cd /home/gokhan/UniverseCreator-otonom/github-pages-deploy
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/UniverseCreator-tools.git
git push -u origin main
```

3. Go to GitHub repo Settings → Pages → Source: Deploy from branch → Select "main" → Folder: "/ (root)"
4. Your site will be live at: `https://YOUR_USERNAME.github.io/UniverseCreator-tools/`
