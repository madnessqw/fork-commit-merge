# ASCII Art Generator Pro - Product Spec

## Overview
Text to ASCII Art converter for developers. Generate stylish ASCII banners, logos, and text art for code comments, documentation, and CLI outputs.

## Features
1. **Text to ASCII Conversion**
   - Multiple font styles (Standard, Big, Small, Script, Shadow, Banner)
   - Real-time preview
   - Copy to clipboard
   - Download as .txt file

2. **Font Options**
   - Block letters
   - Bubble text
   - Digital/7-segment
   - Gothic/Old English
   - Reverse/Flip text
   - Slanted/Italic

3. **Customization**
   - Width adjustment (auto-fit or custom)
   - Character set selection
   - Horizontal/vertical layout

## Technical Spec
- Pure HTML/JS (no backend needed)
- figlet.js library for ASCII generation
- Responsive design
- Dark theme default

## Monetization
- Free: Basic fonts (5 styles)
- Pro ($19): All 30+ fonts, custom character sets, batch export, API access
