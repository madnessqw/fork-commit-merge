# Diff Tool Pro - Product Spec

## Overview
Professional code and text comparison tool for developers. Compare files, snippets, and documents side-by-side with syntax highlighting. Track changes, merge conflicts, and visualize differences.

## Features
1. **Text Comparison**
   - Side-by-side diff view
   - Inline diff mode
   - Line-by-line comparison
   - Character-level highlighting

2. **Code Support**
   - Syntax highlighting for 50+ languages
   - Git-style diff output
   - Ignore whitespace option
   - Case sensitivity toggle

3. **Input Methods**
   - Paste text directly
   - Upload files
   - Drag & drop
   - URL fetch (raw files)

4. **Export & Share**
   - Copy diff as HTML
   - Export to patch file
   - Shareable links
   - Embed in documentation

## Technical Spec
- HTML/JS frontend
- diff-match-patch library
- Prism.js for syntax highlighting
- Dark theme default
- Mobile responsive

## Monetization
- Free: Basic text diff, 3 file comparisons/day
- Pro ($19): Unlimited comparisons, syntax highlighting, patch export, API access
