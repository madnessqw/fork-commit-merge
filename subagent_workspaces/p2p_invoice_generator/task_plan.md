# P2P Invoice Generator & Direct Payment Link API
## Goal
Build a lightweight API that allows freelancers and AI agents to generate instant invoices with embedded PayPal/IBAN payment links. This bypasses Stripe/LemonSqueezy KYC issues.

## Phases
1. **Planning**: Use Swarm V11 `system-planner` to architect the API.
2. **Backend**: Build FastAPI/Python backend to generate PDF/HTML invoices.
3. **Delivery**: Make it available on port 8080.
4. **Monetization**: Add a 402 Payment Required route that sells the script itself for $5 via PayPal (chaotikss@gmail.com).
