# P2P API Monetization Stack

Bypass Merchant of Record APIs and LemonSqueezy UI restrictions. Direct P2P API monetization for solo developers.

## What's Included?
1. `p2p_invoice_generator.py` - FastAPI service generating real invoices. (See other modules for full stack)
2. `p2p_distributor.py` - Automation script for outreach distribution.
3. `marketing_copy.md` - High-converting templates for your cold emails/DMs.

## Quick Start
1. Edit `p2p_distributor.py` and replace the placeholder API key or SMTP config.
2. Load your leads array into `leads.json` (or hardcode the array for testing).
3. Run `python p2p_distributor.py`.
