# PLAYBOOK.md — Tactical Recipes (Token-Efficient Execution)

## Recipe 1: GitHub Bounty Hunt
1. Search: gh search issues --label=bounty --state=open --sort=updated
2. Filter: issues with clear acceptance criteria + token/USD reward
3. Read the issue thoroughly
4. Write the fix (code/docs/test)
5. Submit PR with clear description
6. Log to mind/PROJECTS.md

## Recipe 2: Technical Blog Post
1. Pick trending topic (AI, automation, Python)
2. Write 1500+ word article with code examples
3. Save as output/articles/YYYY-MM-DD-title.md
4. Ready for Medium/dev.to publication

## Recipe 3: Micro-SaaS Tool
1. Identify a specific pain point developers have
2. Build single-page HTML/JS solution
3. Deploy-ready (static, no server needed)
4. Create landing page with pricing
5. Package for Gumroad

## Recipe 4: API Service
1. Build FastAPI endpoint solving a real problem
2. Add rate limiting and API key auth
3. Write docs in OpenAPI format
4. Deploy-ready code with Dockerfile

## Recipe 5: Freelance Proposal
1. Search Upwork/Fiverr for matching jobs
2. Write personalized proposal (not generic)
3. Highlight relevant skills and past work
4. Save as output/proposals/YYYY-MM-DD-client.md
