## Polar Checkout Oluşturma (PRIORITE)
- **41 üründe checkout URL eksik** — hepsine Polar checkout oluştur.
- Polar API Key: `POLAR_OAT` env var üzerinden yüklenir (`config/polar.json` kaynak).
- **Polar Checkout Kuralları:**
  - **Minimum fiyat:** $0.50 (cent: 50) — $0.10 çalışmaz, Polar reddeder
  - **Price payload:** `amount_type: "fixed"`, `price_amount: 100`, `price_currency: "usd"`
  - **OAT ile organization_id GÖNDERİLMEZ** — hata verir
  - **Çalışan test:** deneme-test ürünü $1 ile başarılı checkout oluşturdu
- Detaylı kurallar için `skills/POLAR_CHECKOUT.md` truth source kabul et.
- `live` ve `ready_for_payment` ürünlerde checkout gap varsa önce onları yap.
- Static ürünlerde reusable Polar checkout link üret; kısa ömürlü session URL'yi katalog checkout gibi kullanma.
- Fiyat kaynağı: önce `products/<slug>/product.json`, parse edilemiyorsa site/kod dosyalarından fiyat keşfet.
