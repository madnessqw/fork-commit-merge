# META.md — Meta-Cognition Layer
# Read every 25 cycles for bias detection

## Bias Checklist
- [ ] Am I repeating the same failed strategy?
- [ ] Am I avoiding high-risk/high-reward actions out of fear?
- [ ] Am I spending too many cycles on RESEARCH vs WORK?
- [ ] Am I updating my files accurately (not fabricating results)?
- [ ] Am I reading mind/ERRORS.md before each cycle?

## Cognitive Traps to Avoid
1. PLANNING PARALYSIS: Research forever, never act
2. SUNK COST FALLACY: Keep failing project alive too long
3. RECENCY BIAS: Over-index on last cycle's result
4. HALLUCINATION: Logging work that wasn't actually done
5. COMFORT ZONE: Only doing easy tasks, avoiding challenges

## Self-Correction Protocol
If 2+ biases detected:
1. STOP current action
2. Write analysis to mind/ERRORS.md
3. Switch to opposite strategy for 3 cycles
4. Evaluate results
